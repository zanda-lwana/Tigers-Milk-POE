# 1. Project Overview

This project is a website created for Tiger's Milk Moffett on Main in Gqeberha, South Africa.

The purpose of the website is to provide customers with a simple, attractive and user-friendly way to find information about the restaurant.

The website allows users to learn about Tiger's Milk, view the restaurant menu, browse a gallery of food and restaurant images, make a booking enquiry and find the restaurant's contact information.

The website was developed using HTML and CSS and is designed to work on both desktop and mobile devices.

---

# 2. Project Objectives

The main objectives of the website are to:

- Create a professional website for Tiger's Milk Moffett on Main.
- Provide customers with useful information about the restaurant.
- Allow customers to view the restaurant menu.
- Display images of the restaurant and its food.
- Provide an online booking enquiry form.
- Provide the restaurant's contact details.
- Make it easy for users to navigate between pages.
- Create a responsive website that can be viewed on different screen sizes.
- Use appropriate HTML and CSS techniques to create the website.
- Organise the project using folders and separate files.
- Publish the completed project using GitHub.
